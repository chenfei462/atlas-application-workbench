# Atlas 硕士申请文书：官方写作要求研究

查阅日期：2026-10-13。范围：个人本地使用的香港／新加坡硕士申请工作台，兼顾金融、计算机、商业分析及一般授课硕士。本文只做研究与产品规则建议，不代表任何学校的招生评分，也不能证明某种写法导致录取。

## 1. 六项官方来源及适用边界

### S1 — LSE: Statement of academic purpose

- 官方页：[Statement of academic purpose](https://www.lse.ac.uk/study-at-lse/Graduate/Prospective-students/Supporting-documents/Statement-of-academic-purpose)
- 访问：2026-10-13；层级：LSE graduate 通用文书指导，具体项目要求优先。
- 摘要：说明学术兴趣、准备、项目选择理由及目标；相关课程和经历应证明适合度。鼓励由学习或工作中的未解问题引出动机，并解释项目如何补足知识与能力。通用预期为 1,000–1,500 **words**，项目另有要求时遵从项目。要求原创、校对、针对项目；避免排名及城市赞美，页眉或页脚含姓名及项目名。
- 可转规则：采用“问题 → 准备 → 项目资源 → 目标”的逻辑；长度及格式仅用于适用的 LSE 申请，不推广为港新标准。

### S2 — University of Oxford Careers: Personal statements for further study

- 官方页：[Personal statements for further study](https://www.ox.ac.uk/careers/careers-guidance/further-study/personal-statements-for-further-study)
- 访问：2026-10-13；层级：大学职业指导服务的进一步学习写作建议，**不是 Oxford 所有项目的统一招生要求**。
- 摘要：分别回答为何学习该领域、为何该项目、相关经验如何支持胜任、未来方向。不同申请应调整重点。以能力证据支持判断，保持专业且清晰的语言，避免无证据的恭维及堆砌人名；反复修订并请人审稿。该页对无字数要求的长度仅作建议。研究计划通常用于博士及部分研究硕士，应根据学科和项目另行准备。
- 可转规则：检查题目覆盖、经历与能力之间的解释、未来计划与课程连接；单独记录学校的 AI 政策，不能把该页对 AI 的一般意见当作每校的禁令。

### S3 — NUS Computing: MComp (with Specialisations) Application Information

- 官方页：[Application Information](https://www.comp.nus.edu.sg/programmes/pg/misc/application/)
- 访问：2026-10-13；层级：NUS Master of Computing with Specialisations。网页标题显示 InfoSec，但正文说明 Computer Science、Information Systems、Infocomm Security 三个方向的申请。
- 摘要：Personal Statement 为必交材料；须简洁说明申请原因、该领域的准备、未来职业计划，以及有助于判断研究生学习能力与动机的背景和兴趣。CV 另外概述教育、工作和成就。已读公开页未列出 PS 数值字数上限。
- 可转规则：可以迁移“动机／准备／计划”三项检查；不得把 NUS 本科、PhD、临床心理学或其他硕士的限制填入本项目。长度保留“待查申请系统”。

### S4 — NUS: MSc in Business Analytics Application Guide, AY2027/28

- 官方 PDF：[Application Guide, AY2027/28](https://msba.nus.edu.sg/wp-content/uploads/2026/09/Application-Guide-for-MSBA-AY2027_14-Sep.pdf)
- 官方入口核验：[Apply Now](https://msba.nus.edu.sg/apply-now/) 当季 Application Checklist 链接指向此 PDF。
- 访问：2026-10-13；层级：NUS MSBA，August 2027 intake；关键要求见第 7–8 页。
- 摘要：必答题针对感兴趣行业的 AI 与商业分析趋势，要求观点、已采取行动、短期及中期计划。可提交英文书面回答（最多 350 **words**）、三分钟视频或两者，视频被优先推荐。上传 PS 文件仍不能代替 mandatory supplementary questions。奖学金有独立领导力题目及上限；还有 AI 工具使用声明，须如实填写。
- 可转规则：按实际题目分别组织回答、分别计数；不要以通用长篇 SOP 替代。以上题目、长度和视频要求只适用此项目及年度。

### S5 — CUHK Business School Master's: Application Procedures

- 官方页：[Application Procedures](https://masters.bschool.cuhk.edu.hk/apply/)
- 访问：2026-10-13；层级：CUHK Business School 页面覆盖的硕士申请流程，金融等具体项目和申请系统另行确认。
- 摘要：线上流程包括 Personal Statement 与 CV；所需文件清单在申请系统内。公开页说明每个支持文件不得超过 2 MB；已读页面未给 PS 题目、语言或词数。
- 可转规则：为具体项目保留来源、题目、语言、计数单位、提交位置及文件大小；缺失要求显示待核验，不编造“CUHK 统一 500 词／两页”。本科 Non-JUPAS 的限制不可挪用。

### S6 — HKUST: MSc in Information System Management, Application Schedule & Procedures

- 官方页：[Application Schedule & Procedures](https://mscism.hkust.edu.hk/admissions/application-schedule-procedures)
- 访问：2026-10-13；层级：HKUST MScISM 2027/28 申请流程，适用于信息系统与商业技术方向。
- 摘要：要求完整线上申请表，其中包括 Personal Statement；CV 与其他材料另列。已读公开页未列数值 PS 长度或具体题目。
- 可转规则：将 PS 与 CV 作为不同材料，写作前核验申请表的实际题目与长度。HKUST 本科、4+1 路径或其他 MSc 的要求不能合并成全校默认。

## 2. 原创综合：Atlas 的写作逻辑

以下是上述来源启发的产品设计，**不是各学校额外规定**。

1. **先确认问题，再写文章。** 当季具体项目／申请系统的题目与限制优先；要求不明时记录缺口。通用结构是辅助框架，不覆盖项目题目。[S1](https://www.lse.ac.uk/study-at-lse/Graduate/Prospective-students/Supporting-documents/Statement-of-academic-purpose)、[S4](https://msba.nus.edu.sg/wp-content/uploads/2026/09/Application-Guide-for-MSBA-AY2027_14-Sep.pdf)
2. **动机应有内容。** 用真实课程、实习或阅读中遇到的问题说明兴趣如何形成；并解释为什么现在需要硕士训练。无需强行制造戏剧性开头。[S1](https://www.lse.ac.uk/study-at-lse/Graduate/Prospective-students/Supporting-documents/Statement-of-academic-purpose)、[S2](https://www.ox.ac.uk/careers/careers-guidance/further-study/personal-statements-for-further-study)
3. **能力主张要能回溯。** 从现有 evidence 中选相关经历，写清本人职责、行动、结果与学到什么。“行动／结果／反思”是 Atlas 的整理法，不是全校统一格式。可量化的真实结果优先；没有数字时使用真实交付物、验证、反馈或方法变化，不能补造指标。团队结果与个人贡献分开。
4. **项目匹配要解释用途。** 对“我已有的准备 → 还缺的能力 → 已核验项目资源 → 下一步目标”逐项连接。课程、方向或项目机会必须有当前官方来源；不保证某课程一定开课，也不暗示与未接触的教授已有合作。[S1](https://www.lse.ac.uk/study-at-lse/Graduate/Prospective-students/Supporting-documents/Statement-of-academic-purpose)、[S2](https://www.ox.ac.uk/careers/careers-guidance/further-study/personal-statements-for-further-study)
5. **使用申请人的语气。** 先保留事实与本人思路，再改善段落和语言。复查具体学校的 AI／原创性规定及声明；不将生成内容自动标成可提交版本。[S1](https://www.lse.ac.uk/study-at-lse/Graduate/Prospective-students/Supporting-documents/Statement-of-academic-purpose)、[S4](https://msba.nus.edu.sg/wp-content/uploads/2026/09/Application-Guide-for-MSBA-AY2027_14-Sep.pdf)

网上公开的录取案例可以观察结构、细节密度与表达方式，但不能据此确认作者身份、证明录取原因或估算个人录取概率。不得照抄他人经历或成句。写作规则应由官方题目和本人证据决定。

## 3. 文书类型与计数单位

| 项目 | Atlas 应如何处理 |
| --- | --- |
| PS / SOP / Statement of academic purpose | 名称存在重叠，按学校实际题目决定内容；不以名称机械决定“个人故事比例”或“研究比例”。授课硕士通常先证明动机、准备及学习目标。 |
| Research proposal | 仅在项目要求时建立独立文档与清单；研究问题、已有研究、方法及可行性需要另做学科核验。不能把博士／研究硕士的研究计划强加给所有授课硕士。来源：[Oxford further study](https://www.ox.ac.uk/careers/careers-guidance/further-study/personal-statements-for-further-study)。 |
| Words | 保存官方限制及文本原单位。英文词数本地可给估算，但连字符等分词方法可能不同；以申请系统最终校验为准。 |
| Characters | 字符数与词数不同，分别记录是否包含空格／换行。中文字符不能直接等同英文 words。 |
| Pages / file size | 页数依赖排版，应对最终导出文件检查；2 MB 文件限制不是文章长度。 |
| Tokens | 仅为模型运行预算，不作为学校 words／characters 的替代，也不展示成“官方字数”。 |
| 未公开限制 | 显示“尚未核验”，允许用户记录申请表要求；不能用其他学校的默认值制造通过状态。 |

## 4. 写作简报字段（writing brief）

| 字段 | 内容与目的 |
| --- | --- |
| 申请目标 | 学校、校区、准确项目名、方向、学位类型、入学年度。防止误用本科或其他年度规则。 |
| 官方要求 | 来源 URL、页面标题、访问日期、适用项目／年度、要求已核验／待核验、提交位置。 |
| 文书题目 | 用户从官方来源保存题目；若有多个小问，各自列出，逐项对应文章段落。 |
| 文书规格 | 类型、提交语言、限制数值、单位、上限／建议区间、字符是否含空格、格式／文件大小。数值允许为空。 |
| 动机与问题 | 感兴趣的具体问题、来源经历、为何现在读硕士。 |
| 学术准备 | 相关课程、方法、技能及对应 evidence ID；不重复抄整个 CV。 |
| 主要证据 | 2–3 项相关 evidence ID，以及本人角色、行动、结果、反思；数字及成果须本人确认。 |
| 项目匹配 | 已核验课程／机会／方法、官方 URL、查阅日期、准备基础、学习缺口及用途。 |
| 未来方向 | 近期及中期目标，硕士训练如何帮助下一步；不强迫写未经确定的岗位承诺。 |
| 真实性与使用政策 | 事实待确认项、学校 AI／原创性政策 URL 与核验日期、需要填写的声明。政策未知时标明未知。 |
| 修订与提交 | 草稿版本、针对具体项目的修改记录、人工审稿状态、最终导出预览及提交核验日期。 |

首屏可先展示题目、规格、动机、证据、项目匹配和目标；来源与政策放入可展开的核验区。采用现有 essay / evidence / version 模型，不需要外部云端服务来保存这份个人简报。

## 5. 质量检查清单（不计算录取概率）

检查项用“已满足／待补充／需本人核实／不适用”四类状态；每项指出缺失内容或需要修改的位置。计数和项目绑定可以自动核验；真实性、反思深度和目标可行性必须由本人或审稿者判断。

- [ ] 当季、具体项目的题目与规格已核验；全部小问均有回应。
- [ ] 动机有真实问题或经历支撑，解释为何需要进一步学习。
- [ ] 学术准备与项目相关；每项主要能力主张有证据或具体例子。
- [ ] 本人角色、行动及结果清楚，团队成果没有写成个人独立成果。
- [ ] 经历说明学到了什么，以及后续学习需求；没有重复罗列 CV。
- [ ] 学习缺口与已核验的课程／机会形成连接，避免排名与空泛赞美。
- [ ] 职业／学术目标与拟学能力一致，没有虚构课程、联系或承诺。
- [ ] 事实、数值、日期与 evidence / CV / 成绩材料相符，未确认项已经处理。
- [ ] 官方要求的语言、words / characters / pages / file size 分别符合；未核验项不标通过。
- [ ] 用语清晰专业，段落连贯，校名项目名准确，已校对并完成本人审阅。
- [ ] 适用的原创性／AI 声明如实处理；文件为正确的最终版本与提交位置。

可展示“题目覆盖 3/4、待确认事实 2 项、已核验项目匹配 1 项”等可解释结果。不要输出“录取概率 82%”“招生官评分 9/10”或“达到录取级别”，因为这些官方页面未提供对应验证依据。

## 6. 研究局限与维护

本次直接阅读官方网页及当季官方 PDF，未复制完整示例或文书全文。每项来源仅作短摘要，无长段引用。CUHK Business School 和 HKUST MScISM 的公开页只确认材料与流程，具体文书题目和数值长度仍需在相应申请表核验。官方信息可能更新，提交前重新核对。遇到学校通用页与项目页冲突，优先当前具体项目要求并记录冲突；未能核实时保留待核验状态。
